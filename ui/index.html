열쇠 만드는 법 처음 한 번, 10분쯤. 브라우저에서 하고 이 창으로 돌아와 마쳤어요를 누르세요.

1. 프로젝트 만들기

  1. 열기를 누르면 브라우저에 구글 클라우드의 '새 프로젝트' 화면이 열립니다. 로그인하라고 하면 사진을 올릴 구글 계정으로 합니다.
  2. 프로젝트 이름에 아무 이름이나 넣고 만들기 (Create). 예:

확인 화면 왼쪽 위 프로젝트 칸에 방금 만든 이름이 보이면 맞습니다(보통 '시작하기' 화면이 열립니다).

  • 약관·국가를 물어요 → 구글 클라우드를 처음 쓰는 계정이면 서비스 약관 화면이 먼저 나옵니다. 국가를 고르고 동의하면 됩니다.
  • 무료 체험·결제 안내가 떠요 → 이 일에는 결제가 필요 없습니다. 닫고 넘어가면 됩니다.
  • 쓰던 프로젝트가 이미 있어요 → 그 프로젝트를 써도 됩니다. 위쪽 프로젝트 칸에서 고른 뒤 다음 단계로 가세요.

2. Photos Library API 켜기

  1. 열기로 'Photos Library API' 화면을 엽니다. 맨 위 프로젝트 칸이 1단계에서 만든 것인지 봅니다. 다르면 눌러서 바꿉니다.
  2. 파란 사용 (Enable) 버튼을 누릅니다.

확인 버튼이 관리 (Manage)로 바뀌거나 API 세부정보 화면으로 넘어가면 맞습니다.

  • 사용 대신 관리가 보여요 → 이미 켜져 있습니다. 다음 단계로 가세요.
  • 비슷한 이름이 여럿이에요 → 'Photos Library API'를 고릅니다. 'Google Photos Picker API'는 다른 것입니다.

3. 동의 화면 만들기

  1. 'Google 인증 플랫폼' 화면에서 시작하기 (Get started).
  2. 앱 이름 , 사용자 지원 이메일은 내 Gmail → 다음. 대상은 외부 (External) → 다음.
  3. 연락처 정보에 내 Gmail → 다음 → 정책 동의에 체크 → 계속 → 만들기 (Create).

확인 왼쪽 메뉴에 개요·브랜딩·대상·클라이언트·데이터 액세스가 보이면 맞습니다.

  • 시작하기가 안 보이고 설정 화면이 나와요 → 이미 만든 것입니다. 다음 단계로 가세요.
  • '내부'는 고를 수 없어요 → 개인 Gmail이면 그게 맞습니다. 외부를 고릅니다.

4. 테스트 사용자 넣기

  1. '대상' (Audience) 화면의 테스트 사용자에서 사용자 추가 (Add users).
  2. 사진을 올릴 구글 계정 이메일을 넣고 저장 (Save).
  3. 게시 상태는 테스트 (Testing) 그대로 둡니다. 앱 게시 (Publish app)는 누르지 않습니다.

확인 테스트 사용자 목록에 그 이메일이 보이면 맞습니다.

  • 로그인 때 '액세스 차단됨'(403 access_denied)이 나와요 → 로그인한 계정이 이 목록에 없는 것입니다. 넣은 뒤 다시 로그인하세요.
  • 계정이 여러 개예요 → 모두 넣어도 됩니다(최대 100명).

5. 권한 목록 넣기

  1. '데이터 액세스' (Data Access) 화면에서 범위 추가 또는 삭제 (Add or remove scopes).
  2. 오른쪽 창 맨 아래 직접 범위 추가 (Manually add scopes) 칸에 아래 목록을 붙여 넣고 표에 추가 → 업데이트 (Update) → 화면 아래 저장 (Save).
https://www.googleapis.com/auth/photoslibrary.appendonly
https://www.googleapis.com/auth/photoslibrary.readonly.appcreateddata
openid
https://www.googleapis.com/auth/userinfo.email

확인 범위 목록에 photoslibrary가 들어간 두 줄(appendonly, readonly.appcreateddata)이 보이면 맞습니다.

  • 표에 Photos 범위가 없어요 → 2단계에서 API를 켰는지, 같은 프로젝트인지 봅니다. 직접 범위 추가 칸에 붙여 넣으면 됩니다.
  • 검토가 필요하다는 경고가 떠요 → 앱을 게시할 때만 필요한 검토입니다. 테스트 상태로 쓰면 그대로 둡니다.

6. 열쇠 만들고 JSON 받기

  1. '클라이언트' (Clients) 화면에서 클라이언트 만들기 (Create client).
  2. 애플리케이션 유형은 데스크톱 앱 (Desktop app), 이름은 아무거나 → 만들기.
  3. 뜨는 창에서 바로 JSON 다운로드 (Download JSON).

이 창을 닫으면 JSON을 다시 받을 수 없습니다(2025년 6월부터 구글 정책). 놓쳤으면 클라이언트를 하나 더 만드세요.

확인 '다운로드' 폴더에 client_secret_….json 파일이 생기면 맞습니다.

  • 창을 닫아 버렸어요 → 클라이언트를 하나 더 만들어 그 창에서 받습니다. 먼저 만든 것은 지워도 됩니다.
  • 유형을 '웹 애플리케이션'으로 만들었어요 → 이 프로그램에서는 안 됩니다. 데스크톱 앱으로 새로 만드세요.

7. 열쇠 파일 고르기

  1. 위 열쇠 파일 칸의 열쇠 파일 선택(오른쪽 위 버튼과 같음)을 누릅니다.
  2. '다운로드' 폴더의 client_secret_….json을 고릅니다.

확인 열쇠 파일 칸이 '등록됨 · 프로젝트 …'로 바뀌면 맞습니다. 다음 단계로 저절로 넘어갑니다.

  • 'JSON 파일이 아닙니다', '열쇠 파일 형식이 아닙니다' → 6단계에서 받은 client_secret_….json을 골랐는지 봅니다.
  • '웹 애플리케이션 유형 열쇠입니다' → 6단계를 데스크톱 앱으로 다시 합니다.

8. 구글 로그인

  1. 구글 로그인을 누르면 브라우저가 열립니다. 4단계에 넣은 계정을 고릅니다.
  2. 'Google에서 확인하지 않은 앱' 화면이 나오면 계속. 안 보이면 고급 → '…(으)로 이동'.
  3. 권한 칸을 모두 체크 → 계속. '로그인을 마쳤습니다'가 보이면 이 창으로 돌아옵니다.

확인 구글 로그인 칸에 내 이메일이 보이면 끝입니다. 화면 맨 아래 다음 →으로 사진 폴더를 고르세요.

  • '액세스 차단됨'(403)이 나와요 → 4단계 테스트 사용자에 그 계정을 넣습니다.
  • '구글 포토에 사진 추가' 권한에 체크하지 않았다고 나와요 → 다시 로그인하고 권한을 모두 체크합니다.
  • 7일 뒤 다시 로그인하래요 → 테스트 상태 앱은 7일마다 다시 로그인해야 합니다(구글 정책).

콘솔 화면 이름은 2026년 11월 기준입니다. 이름이 다르면 괄호 안 영어 이름이나 같은 자리의 버튼을 찾으세요.
