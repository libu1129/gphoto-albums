열쇠 만드는 법처음 한 번, 10분쯤. 각 단계의 열기를 누르면 브라우저에서 그 화면이 열립니다.
  1. 새 프로젝트를 만듭니다. 이름은 아무거나(예: 사진 올리기).
  2. Photos Library API를 찾아 사용을 누릅니다.
  3. Google 인증 플랫폼에서 시작하기 → 앱 이름·내 이메일 → 대상 외부.
  4. 대상 → 테스트 사용자에 사진을 올릴 계정 이메일을 추가합니다.
  5. 클라이언트 → 클라이언트 만들기 → 유형 데스크톱 앱 → JSON 다운로드.
  6. 받은 client_secret_….json을 위의 열쇠 파일 선택으로 고릅니다.

로그인 때 '확인되지 않은 앱' 경고가 나오면 직접 만든 앱이라 그런 것이니 계속을 누르고, 권한 칸은 모두 체크하세요. 시험 상태 앱은 7일마다 다시 로그인해야 합니다.
